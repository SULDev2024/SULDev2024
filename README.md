## 🚀 Featured Projects

### 🎙️ Automated Meeting Minutes

AI-powered system that converts meeting recordings into structured meeting minutes using speech transcription, speaker diarization, LLM analysis, summarization, and action-item extraction.

**Technologies:** Python • FastAPI • React • Groq • OpenAI • LLMs

[View Project](https://github.com/SULDev2024/Automated-Meeting-Minutes)

---

### 🛡️ AI Media Watch

Multimodal AI system designed to analyze videos for potential scams, misinformation, and manipulation using speech, visual, and language analysis.

**Technologies:** Python • FastAPI • Computer Vision • Whisper • LLMs • Docker

---

### 🤖 AR + AI Robot Teacher

Experimental AR system where an AI-powered virtual robot understands its physical surroundings, finds objects, moves through the environment, explains objects, and interacts with users.

**Technologies:** Three.js • WebXR • Computer Vision • Local LLMs • Spatial AI • AR

---

### 🏥 Hospital Digital Twin

Interactive 3D hospital environment designed for experimenting with digital twins, spatial intelligence, and AI-assisted navigation.

**Technologies:** Blender • Three.js • 3D Modeling • JavaScript • Spatial Computing
